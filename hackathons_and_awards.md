# Featured Hackathons & Projects

## 1. ReliefGrid — CockroachDB x AWS Hackathon
*   **Theme:** Build with Agentic Memory (Distributed transactional states + pgvector)
*   **Role:** Founder, AI Product Engineer, Software Architect, Full-Stack Developer, Product Designer.
*   **Problem:** Emergency response systems struggle with fragmented coordination and context loss across incident shifts.
*   **Solution:** Built a multi-agent orchestration architecture utilizing a persistent vector memory layer, enabling agents to retain spatial, logistical, and historical context.
*   **Key Learnings:** Multi-agent architectures demand high transactional stability (CockroachDB); AI memory is as critical as reasoning models; system design must account for LLM latencies.

# Lessons from Competitive Building

*   **Ship Functional Prototypes First:** Get code running in production early; iterate rapidly.
*   **Validate via Running Software:** Focus on building verifiable features rather than slideshow designs.
*   **Build Architecture for Evolution:** Keep database tables and API schemas clean so the code can scale post-hackathon.
*   **Document Early:** Clear documentation (PRDs, diagrams) ensures teams remain aligned under tight deadlines.
